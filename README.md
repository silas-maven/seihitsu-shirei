# Seihitsu Shirei

Private macOS AI copilot HUD.

## Purpose

A native, floating AI interface designed to remain outside ordinary screen-capture and screen-sharing surfaces where macOS permits. It should provide an unobtrusive, always-available copilot layer without becoming part of the captured workspace.

## Intended first surface

- macOS menu-bar application
- Borderless, always-on-top floating panel
- Drag, resize, click-through, and global-hotkey modes
- Native capture-exclusion handling where supported by macOS
- AI-provider adapters for OpenAI, Anthropic, Gemini, and local models
- Optional permitted context from clipboard, OCR, and accessibility APIs

## Scope boundary

This repository currently contains project definition only. No application implementation has been started.

## Name

**Seihitsu Shirei** — 静謐司令 — “quiet command.”
